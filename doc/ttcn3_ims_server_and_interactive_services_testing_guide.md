# Tài Liệu Hướng Dẫn Kiểm Thử Server IMS & Dịch Vụ Tương Tác Bằng TTCN-3 (Theo Chuẩn 3GPP TS 23.228 Annex AC)\n\nTài liệu này được biên soạn cho **Đội Kiểm Thử (QA Team)** để hướng dẫn mở rộng kịch bản **TTCN-3 hiện có** (đang dùng cho VoLTE) phục vụ kiểm thử tự động hệ thống **IMS Core Server và các Dịch Vụ Tương Tác (Mini-App / Data Channel)** mà **không cần điện thoại Android thật**.\n\n---\n\n## 1. Kết Quả Khảo Sát Tuân Thủ Chuẩn 3GPP TS 23.228 Annex AC\n\n> [!NOTE]\n> **ĐÁNH GIÁ TỔNG QUAN**: Luồng bản tin của hệ thống **hoàn toàn tuân thủ tiêu chuẩn 3GPP TS 23.228 Annex AC**.\n> - **Clause AC.7.2.1**: Thiết lập kênh BDC ngay trong bản tin mời cuộc gọi ban đầu (Early Offer INVITE).\n> - **Clause AC.7.3.1**: Tương tác giao diện SBA giữa IMS-AS, DCSF (giao diện DC1) và MF (giao diện DC2).\n> - **Clause AC.7.4.1**: Mở kênh BDC Stream 0 để tải ứng dụng gốc (Root-App / Operator Menu) bằng lệnh HTTP GET /bootstrap.\n> - **Clause AC.7.2.2 & AC.7.3.2**: Gửi bản tin SIP re-INVITE mang thuộc tính `a=3gpp-req-app` để mở thêm kênh ADC Stream 1000 cho các dịch vụ tương tác.\n> - **Clause AC.7.6.1**: Thu hồi cổng và giải phóng tài nguyên trên DCSF, MF khi kết thúc cuộc gọi (SIP BYE).\n\n---\n\n## 2.
